
- **Виявлена вразливість:** Можливість виконання XSS-атаки на сторінці деталей тренування (`/workouts/:id`) через пряму підстановку полів `workout.type` та `workout.details` у `innerHTML`.
- **Спосіб усунення:** Додано функцію екранування спецсимволів `escapeHtml()`, через яку пропускаються всі динамічні дані перед рендерингом у розмітку.
- **Перевірка сховищ та мережі:** `localStorage` та `IndexedDB` не містять конфіденційних даних; секретні ключі в коді відсутні; розгортання здійснюється по HTTPS (GitHub Pages).
